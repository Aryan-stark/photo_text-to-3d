Image/Text to 3D Model Generator
This project demonstrates generating 3D models from either text prompts or 2D images using machine learning models. The output is a 3D point cloud or mesh file (e.g., .ply, .obj), and can be visualized using Open3D.

Technologies Used
Python
OpenAI's Point-E (for text-to-3D)
OpenAI's Shap-E (alternative for text-to-3D and image-to-3D)
Open3D (for visualization)
PyTorch (for model loading and inference)
Google Colab (for running text-to-3D if needed)
